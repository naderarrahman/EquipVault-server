- **Health Check Endpoint:** [`GET /`](https://equip-vault-server.vercel.app/)

---

## ✨ Key Engineering Highlights

- **Modular Layered Architecture:** Clean separation of concerns across `routes`, `controllers`, `middlewares`, and `config` layers using TypeScript.
- **Role-Based Access Control (RBAC):** Session token verification integrated with Better Auth's MongoDB session store, enforcing strict `customer`, `owner`, and `admin` authorization boundaries.
- **Unified Marketplace Aggregation:** Single-roundtrip `GET /api/marketplace/home-data` endpoint combining featured approved listings, dynamic category counts, platform metrics, and verified reviews.
- **Advanced Query Engine:** Server-side regex-escaped keyword search, multi-parameter filtering (category, rental billing cycle, min/max price range, stock availability), and dynamic sorting.
- **Stripe Payment Processing:** Secure payment intent/checkout session creation, transaction verification, and booking payment status synchronization.
- **Serverless-Ready Connection Pooling:** Cached MongoDB client initialization and automated database index setup (`ensureDatabaseIndexes`) optimized for Vercel serverless cold starts.

## 🔌 API Reference Overview

### Public & Marketplace Endpoints
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Server health check & timestamp |
| `GET` | `/api/marketplace/home-data` | Aggregated featured equipment, category counts, stats & reviews |
| `GET` | `/api/equipment` | Browse approved equipment (`?search=&category=&rentalType=&minPrice=&maxPrice=&availability=&sort=`) |

### Authenticated & Role-Protected Endpoints
| Domain | Base Path | Key Capabilities |
| :--- | :--- | :--- |
| **Equipment** | `/api/equipment` | View single item details (`/:id`), create listing (`POST /`), owner inventory (`/my-equipment`), update & delete own items |
| **Bookings** | `/api/bookings` | Create rental request, customer booking history (`/my-bookings`), owner incoming requests (`/owner`), status updates |
| **Favorites** | `/api/favorites` | Toggle saved equipment, check favorite status (`/check/:equipmentId`), list saved items (`/my-favorites`) |
| **Payments** | `/api/payments` | Initialize Stripe payment session, verify payment completion & record transaction |
| **Dashboards** | `/api/dashboard` | Role-specific metrics (`/owner-overview`, `/customer-overview`) |
| **Admin** | `/api/admin` | Platform KPIs (`/stats`), user management (`/users`), listing approval queue (`/equipment`), bookings & payment logs |

## 🔐 Environment Variables

Create a `.env` file in the root directory based on `.env.example`:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/?retryWrites=true&w=majority
CLIENT_URL=http://localhost:3000
STRIPE_SECRET_KEY=sk_test_your_stripe_secret_key
```

## 🚀 Getting Started (Local Development)

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/naderarrahman/EquipVault-server.git](https://github.com/naderarrahman/EquipVault-server.git)
   cd EquipVault-server
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   ```bash
   cp .env.example .env
   # Update MONGODB_URI, CLIENT_URL, and STRIPE_SECRET_KEY in .env
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   The API will run at `http://localhost:5000`.

### Available Scripts
- `npm run dev` — Starts the local server with hot-reload via `tsx watch`
- `npm run typecheck` — Runs strict TypeScript type checking (`tsc --noEmit`)
- `npm run build` — Compiles TypeScript to `dist/`
- `npm run vercel-build` — Bundles the Express app into a single CommonJS entrypoint (`api/index.cjs`) via `esbuild`
